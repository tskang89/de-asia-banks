# 독일 소재 한·중·일 금융기관 재무 현황

독일 상업등기부(Unternehmensregister)에 공시된 HGB 개별재무제표 69건(2021~2025회계연도)으로 만든 정적 웹사이트.

- 기관 목록: 국가별 15개 기관의 성격, 최근 총자산·부채·자본·당기순이익·직원 수
- 기관 상세: 연도별 대차대조표·손익계산서(셀마다 원문 파일·쪽), 지표, 해설
- 국가별 비교: 상업은행 / 자동차금융 / 증권 / 전체 합산 금액과 비율(규모 가중)

파일: `index.html`, `app.js`, `style.css`, `data.json`(분석 프로젝트의 `analysis/09_site_data.py`가 생성).
빌드 도구 없이 GitHub Pages(브랜치 루트)로 바로 게시된다.
